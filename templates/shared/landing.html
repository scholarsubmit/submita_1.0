What's actually running under the hood

Not marketing claims — this is what each feature does.

✨

AI grading, human-reviewed

Claude assesses a submission against the assignment's instructions and drafts a score and feedback. A lecturer always reviews and approves it before it becomes real.

🔍

Plagiarism detection

Every submission is automatically compared against classmates' submissions for the same assignment — sequence and phrase similarity, not a guess.

📊

Security

Nobody walks in the back door

Especially lecturer accounts — those aren't self-service.

  • ✓ Lecturer accounts are never self-registered. Access is requested, reviewed by an admin, and only created by redeeming a single-use code emailed to one specific address.
  • ✓ Every verification code and invite code is stored as a salted hash — never in plaintext, even in the database.
  • ✓ Repeated failed logins lock the account for 15 minutes and trigger an email alert, slowing down credential-stuffing attempts.
  • ✓ CSRF protection, rate limiting, and security headers are active on every form and endpoint — not just the login page.
  • ✓ Password reset links are single-use, expire in 30 minutes, and immediately invalidate any older link that was requested.
